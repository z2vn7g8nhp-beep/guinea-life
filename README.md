# 豚鼠生活馆 · GuineaLife

一个带有沉浸式实时气象视觉特效与动态换装棕白豚鼠的生活方式 Web App（第一板块：天气与日常穿搭）。

## 核心特性

1. **沉浸式物理感天气引擎 (`RealisticWeatherCanvas`)**
   - 根据时间与天气状态平滑渲染 **黎明 / 白昼 / 黄昏 / 星夜** 大气天穹渐变、立体光影云层、丁达尔体积光束（God Rays）、镜头光晕、闪烁星野与流萤。
   - **真实降水与积雪物理**：三层景深雨线（含风偏倾角）、地面水花飞溅涟漪、前景玻璃水滴折射与滑落轨迹；多景深蓬松雪花与零下结霜边缘暗角；递归分叉闪电与云层内透闪电辉光；流动层状雾霭与烈日热浪微颤。
   - **环境天气白噪音（可选）**：内置零素材依赖的 Web Audio API 实时合成雨声、风声与远雷声景。

2. **动态换装棕白豚鼠 (`GuineaPigMascot`)**
   - 精致绘制的棕白花色荷兰猪（会呼吸、自然眨眼、鼻须微动、双耳摆动、受惊反应与点击摸摸跳起冒爱心）。
   - **6 档气温穿衣 + 天气场景叠加**：从 `-15°C` 极地羽绒派克、热可可与寒风白气，到毛呢大衣烤红薯、麻花针织衫、牛仔背带裤、海岛花衬衫墨镜，再到 `35°C+` 冰感背心与降温冰圈、手持小风扇；遇雨自动穿戴黄色防水雨衣、雨靴并撑起透明泡泡伞。

3. **生活化扩展架构**
   - **今日天气**：实时气象（Open-Meteo 全球城市支持 + GPS 定位）+ 交互式天气换装实验室。
   - **豚鼠衣橱**：试衣间与 8 套天气限定造型一键预览。
   - **生活指南**：穿衣、晾晒、防晒、散步、饮品与通勤 6 项天气联动指数。
   - **更多板块**：预留打卡、心情手账、时令饮食等后续生活板块扩展位。
